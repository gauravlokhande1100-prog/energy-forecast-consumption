3  Annotate data gaps instead of inventing them

NoteLearning objective

You understand why a safety-critical library annotates broken rows instead of interpolating them, and you can assemble the three building blocks mark_outliers, get_missing_weights and WeightFunction into a preprocessing pipeline that complies with the AI Act.

3.1 Why not simply interpolate?

Linear interpolation (see Chapter 4) fills gaps with invented values. For yesterday’s weather forecast that is uncritical; in a high-risk application under Annex III of the AI Act — such as load forecasting for a transmission system operator — it leads to two structural problems:

  1. Auditability disappears. In retrospect an interpolated hour looks to the auditor exactly like a real measurement. But Art. 12 of the AI Act demands that every data-related action remains discoverable in the audit log.
  2. The model learns phantom data. A forecaster that takes the interpolated value as a training target optimises its loss against invented values as well. The expected value of the learned function is biased in favour of the imputer — rather than in favour of reality.

The spotforecast2-safe library therefore follows the “annotate, don’t invent” pattern: broken rows are set to NaN, filled in via forward/backward fill only far enough that the lag operator does not crash, and assigned weight 0 in the training loss. The model sees the compromised rows, but they do not pull the gradient.

3.5 Step 1 — Mark outliers

mark_outliers runs an IsolationForest on each column and replaces detected anomalies with NaN. The parameter contamination is the expected outlier ratio — keep it small, otherwise the algorithm treats regular load peaks as defects too.

from spotforecast2_safe.preprocessing import mark_outliers

df_marked, labels = mark_outliers(
    df_demo.copy(),
    contamination=0.005,
    random_state=1234,
    verbose=True,
)

n_marked = int(df_marked["load"].isna().sum())
print(f"\nMarked rows: {n_marked} ({n_marked/len(df_marked):.2%})")
print(f"The injected spike at {spike_ts}:  {df_marked.loc[spike_ts, 'load']!r}")

The constructed spike was detected — the value is now NaN. The list is part of the audit log.

3.6 Step 2 — Fill gaps and weight them

get_missing_weights does two things in a single call:

  1. Imputation: forward-fill, then backward-fill — so that no NaN remains in the series (a technical prerequisite for the forecaster’s lag operator).
  2. Weighting: for every originally compromised row and for the following window_size hours, the weight is set to 0.0. All other rows receive weight 1.0.

The second point is the decisive step: because the recursive forecaster reads a lag window of size window_size at training time, every row inside that window after a gap is also contaminated — it would be trained against the imputed value as a lag feature. Weight 0 excludes it consistently.

from spotforecast2_safe.preprocessing import get_missing_weights

df_filled, weights = get_missing_weights(
    df_marked,
    window_size=72,
    verbose=True,
)

print(f"\nNaN after imputation:                {int(df_filled.isna().sum().sum())}")
print(f"Rows with training weight 0:        {int((weights == 0).sum()):,}")
print(f"Share of excluded rows:             {(weights == 0).mean():.2%}")

3.7 Step 3 — WeightFunction as a picklable contract

The forecaster accepts a callable for its weight_func parameter, not an array. Background: the lag matrix is max(lags) rows shorter than the original series; a positional handover would create off-by-N errors. WeightFunction resolves this index-based:

from spotforecast2_safe.preprocessing import WeightFunction

weight_func = WeightFunction(weights)
print(weight_func)

# Call with a timestamp index -> numpy array
sample = df_filled.index[:5]
print(f"\nWeights for {sample[0]} ... {sample[-1]}:")
print(weight_func(sample))
WeightFunction(weights_series with 8783 entries)

3.7.1 Edge case: a window entirely in the danger zone

If every row of a lag window carries weight 0, the weighted loss would collapse to 0/0. WeightFunction detects this and returns None; the forecaster interprets None as “uniform weighting”, so the location remains operational.

zero_idx = weights.index[weights == 0]
window_in_gap = zero_idx[:3]
print("Index in danger zone:", window_in_gap.tolist())
print("Return value:", weight_func(window_in_gap))
WeightFunction: all sample weights for the requested index are zero (the window falls entirely within gap-penalty zones). Returning None so ForecasterRecursive uses uniform weighting.

3.7.2 Picklability (CR-2)

So that the entire forecaster — including the weight function — can later be reloaded deterministically, weight_func must be picklable. An ordinary closure would not be; a WeightFunction instance is:

import pickle

raw = pickle.dumps(weight_func)
weight_func_restored = pickle.loads(raw)

original  = weight_func(df_filled.index[:5])
restored  = weight_func_restored(df_filled.index[:5])
print("Original :", original)
print("Restored :", restored)
print("Identical:", bool(np.array_equal(original, restored)))
Original : [1. 1. 1. 1. 1.]
Restored : [1. 1. 1. 1. 1.]
Identical: True

import matplotlib.pyplot as plt
import matplotlib.dates as mdates

view = slice(spike_pos - 5, spike_pos + 90)
idx_view = df.index[view]

    3, 1, figsize=(8.0, 6.5), sharex=True
)

# (1) after mark_outliers: spike is NaN
ax_top.plot(idx_view, df_marked["load"].iloc[view].values / 1000,
            "o-", color="#2E5C8A", linewidth=1.0, markersize=3)

               linestyle="--", label="annotated anomaly")
ax_top.set_ylabel("Load [GW]")
ax_top.set_title("after `mark_outliers`: spike -> NaN")
ax_top.legend(loc="upper right", fontsize=8)
ax_top.grid(True, color="#E5E5E5", linewidth=0.5)

# (2) after get_missing_weights: ffill+bfill closes the gap
ax_mid.plot(idx_view, df_filled["load"].iloc[view].values / 1000,
            "o-", color="#2E7D55", linewidth=1.0, markersize=3)
ax_mid.set_ylabel("Load [GW]")
ax_mid.set_title("after `get_missing_weights`: ffill+bfill (row identity preserved)")
ax_mid.grid(True, color="#E5E5E5", linewidth=0.5)

# (3) training weights
w_view = weights.iloc[view].values
ax_bot.fill_between(idx_view, 0, 1, where=(w_view == 0),
                    step="post", alpha=0.35, color="#888888",
                    label="training weight 0 (danger zone)")
ax_bot.plot(idx_view, w_view, drawstyle="steps-post",
            color="#1A1A1A", linewidth=1.2)
ax_bot.set_ylabel("Weight")
ax_bot.set_ylim(-0.1, 1.2)
ax_bot.set_title(f"Training weighting (window_size=72)")
ax_bot.legend(loc="lower right", fontsize=8)
ax_bot.grid(True, color="#E5E5E5", linewidth=0.5)

ax_bot.xaxis.set_major_locator(mdates.DayLocator(interval=1))
ax_bot.xaxis.set_major_formatter(mdates.DateFormatter("%-d.%-m"))

for ax in (ax_top, ax_mid, ax_bot):
    for s in ("top", "right"):

fig.tight_layout()
plt.show()

The grey area illustrates what window_size=72 means in practice: after each annotated anomaly, another 72 hours are excluded from training because the lag operator would read them as a feature vector. Larger gaps widen the zone accordingly.

```{python}
ax_bot.legend(loc="lower right", fontsize=8)
ax_bot.grid(True, color="#E5E5E5", linewidth=0.5)

ax_bot.xaxis.set_major_locator(mdates.DayLocator(interval=1))
ax_bot.xaxis.set_major_formatter(mdates.DateFormatter("%-d.%-m"))

for ax in (ax_top, ax_mid, ax_bot):
    for s in ("top", "right"):
        ax.spines[s].set_visible(False)

fig.tight_layout()
plt.show()
```

The grey area illustrates what `window_size=72` means in practice: after
each annotated anomaly, another 72 hours are excluded from training
because the lag operator would read them as a feature vector. Larger
gaps widen the zone accordingly.
