2  Loading live data from ENTSO-E

NoteLearning objective

You can use the function download_new_data from spotforecast2_safe.downloader to drop a real electric-load time series for an ENTSO-E market zone into a local CSV, and you can explain how this function guarantees CR-2 (determinism) despite the live API call.

2.1 What the running example in the report was about

The running example in the companion report generates a synthetic load series, because the document must render deterministically and offline. For a course that wants to teach real engineering practice, we replace the synthetic series with real data from the ENTSO-E Transparency Platform — the central database of the European Network of Transmission System Operators for Electricity. ENTSO-E publishes hourly the actual and forecast load for every market zone in Europe.

2.2 AI Act link

Data origin is a central concern of the AI Act: Art. 10(2) obliges providers and deployers to maintain data management and data governance procedures which, among other things, document origin, collection method and assumptions about data processing. By pulling the data directly from the ENTSO-E API rather than from a spreadsheet of unknown origin, we keep the provenance explicit and documentable.

Code rule CR-2 (determinism) would be jeopardised by a live API, because the API returns different values tomorrow than today. We solve this by pinning the date window: all students load exactly the same period (DATA_START to DATA_END), therefore receive byte-identical values, and can compare their results with each other.

2.3 Code in action

import os
from pathlib import Path

# Keep cache directory local to the book rather than in the student's home:
DATA_HOME = Path(__file__).parent.resolve() / "_cache" / "spotforecast2_data" \
    if "__file__" in dir() else Path.cwd() / "_cache" / "spotforecast2_data"

os.environ["SPOTFORECAST2_DATA"] = str(DATA_HOME)

# Fixed constants: the same window for every student
DATA_START = "202401010000"   # 2024-01-01 00:00 UTC
DATA_END   = "202412312300"   # 2024-12-31 23:00 UTC
COUNTRY    = "DE"             # ENTSO-E country code: Germany-Luxembourg market zone

print(f"Data home: {DATA_HOME}")
print(f"Window:    {DATA_START} to {DATA_END}")
print(f"Country:   {COUNTRY}")

import logging
from spotforecast2_safe.downloader.entsoe import download_new_data
from spotforecast2_safe.data.fetch_data import fetch_data, get_data_home

logging.getLogger("spotforecast2_safe.downloader.entsoe").setLevel(logging.INFO)

interim = get_data_home() / "interim" / "energy_load.csv"

if interim.exists():
    print(f"Cache hit, no download needed: {interim.relative_to(DATA_HOME)}")
else:
    api_key = os.environ.get("ENTSOE_API_KEY")
    if not api_key:
        raise RuntimeError(
            "ENTSOE_API_KEY is not set. Register for free at "
            "https://transparency.entsoe.eu/, obtain a token and export "
            "it before rendering: export ENTSOE_API_KEY=...")
    download_new_data(
        api_key=api_key,
        country_code=COUNTRY,
        start=DATA_START,
        end=DATA_END,
        force=True,
    )
    print(f"Download complete, stored at {interim.relative_to(DATA_HOME)}")

2.4 Reading and checking the data

import pandas as pd

df = fetch_data(filename=str(interim))
df.index = pd.to_datetime(df.index, utc=True)

# We focus on the "Actual Load" column:
load_col = next(c for c in df.columns if "Actual" in c and "Load" in c)
y = df[load_col].astype(float).rename("load")

# ENTSO-E delivers 15-minute values for Germany; we aggregate to hourly
# means so that the index matches our hourly weather series and the
# hourly-lag logic of the forecaster.
if y.index.inferred_freq != "h":
    y = y.resample("h").mean()

print(f"Columns in the file: {list(df.columns)}")
print(f"Used column:         '{load_col}'")
print(f"Number of timestamps: {len(y):,}")
print(f"Time window:          {y.index.min()}  ...  {y.index.max()}")
print(f"Missing values:       {int(y.isna().sum())}")
